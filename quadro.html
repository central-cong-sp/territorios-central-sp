🔗 Configurar pasta do Google Drive

Cole o link de compartilhamento de uma pasta publica do Google Drive. Os arquivos PDF dessa pasta aparecao automaticamente aqui.

Como tornar a pasta publica: No Drive, clique com botao direito na pasta > Compartilhar > Alterar para qualquer pessoa com o link > Visualizador.

O Google Drive nao permite listar arquivos via link simples. Informe o ID da pasta e os IDs dos PDFs que quiser exibir (voce pode adicionar quantos quiser).
